## What to build

一栏、三层页面里的前两层，`enter` 向下、`esc` 向上。

**启动落在清单列表页**：内置视图、自定义视图、真实清单平铺成一列，用**前缀字符**区分类型（不靠颜色单独承担）；收集箱置顶；真实清单按项目组归拢，项目组显示成**不可进入的小标题**；每行显示未完成条数；`kind` 是 NOTE 的清单与 `permission` 不是 write 的清单要被标出来且**不可进入**；清单很多时能滚动。

`enter` 进**任务列表页**：当前清单的全部任务（这张先只画标题，行的样子归另一张工单）。`esc` 退回清单列表页，光标**还原到进来的那一行**。空清单显示一句明确的空态文案。**后台全量刷新不得把光标踢回第一行**——两层都要。

**状态栏**常驻：已同步时刻、待推送数量（**非零时高亮**）、当前逻辑日。服务端字段覆盖了本地未推送的改动时要明确告知（「N 处本地改动被覆盖」），而不是看着它静默变回去。全局 `o` 在浏览器里打开当前任务。

**终端能力**：起界面时就要关掉 kitty 键盘协议的推送——开着它，输入法一次上屏超过四个汉字会变成乱码。键位只用终端一定传得上来的那些（字母、数字、F1–F10、`space`、`enter`、方向键、`Ctrl`、`Shift`）。

**一并删掉**：三栏布局、`Tab` 焦点切换、清单浮层、窄屏响应式降级，以及随它们作废的 203 条界面测试。日期解析器此时已无消费者（v2 不做自然语言日期输入），连同它那 75 条测试一起删——**删之前按清路那张工单的核对清单确认一遍**。

## Acceptance criteria

- [ ] 敲 `dida` 落在清单列表页，收集箱在列表最上面
- [ ] 三种行用前缀字符区分，不靠颜色单独承担
- [ ] 真实清单按项目组归拢，项目组是不可进入的小标题
- [ ] 每行显示未完成条数
- [ ] `kind` 是 NOTE 或 `permission` 非 write 的清单有标记且进不去
- [ ] `j`/`k` 与方向键移动光标；清单很多时能滚动
- [ ] 按 `enter` 进入该清单的任务列表页，看到这个清单里的任务
- [ ] 按 `esc` 退回清单列表页，光标还原到进来的那一行
- [ ] 空清单显示明确的空态文案
- [ ] 后台刷新后两层的光标都还在原来那一条上
- [ ] 状态栏显示已同步时刻、待推送数量、当前逻辑日；待推送非零时高亮
- [ ] 服务端覆盖本地改动时，界面明确告知「N 处本地改动被覆盖」
- [ ] 按 `o` 在浏览器里打开当前任务
- [ ] 启动时 kitty 键盘协议推送已关闭（代价是 `ctrl+enter` 收不到，而键位表本来就不依赖它）
- [ ] 三栏布局、`Tab` 焦点、清单浮层、窄屏降级已删除；v1 的 203 条界面测试已删除
- [ ] 日期解析器与它的 75 条测试已删除，没有残留消费者
- [ ] `uv run pytest` 全绿
