## What to build

任务详细页里三个「从已有选项里挑一个（或几个）」的字段编辑。

- **所属清单**：从我的清单里挑一个，任务**真的搬过去**——走搬运端点，**不是**把它当成一次普通的字段更新。搬运在收集箱与真实清单之间双向可用。
- **优先级**：在无 / 低 / 中 / 高之间挑。注意服务端的线上编码（`0/1/3/5`）不是用户语言，界面只说这四档。
- **标签**：从**已有的**标签里多选给任务打上。要**如实告知**不能在客户端里新建标签——要打一个不存在的标签得回官方客户端；更不能删除标签（API 也没有删除端点）。

三个字段都遵循详细页已经定下的规矩：改完立刻推送，底部常驻「已保存 / 待推送（N）」。

## Acceptance criteria

- [ ] 所属清单能从我的清单里挑一个，任务真的搬过去
- [ ] 搬运走搬运端点，而不是普通字段更新；有测试钉死请求形状
- [ ] 收集箱与真实清单之间双向可搬
- [ ] 优先级能在无 / 低 / 中 / 高之间改
- [ ] 标签能从已有标签里多选打上
- [ ] 明确告知不能在客户端新建标签，要新标签得回官方客户端
- [ ] 三个字段都遵循「改完立刻推送 + 底部常驻状态」
- [ ] 搬运后目标清单的列表里有这条任务，原清单的列表里没有
