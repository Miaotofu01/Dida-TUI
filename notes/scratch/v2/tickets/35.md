## What to build

三个内置视图就是三个写死的视图定义，走和自定义视图**同一条**求值路径：视图定义 + 全量任务缓存 + 当前逻辑日 → 一份排好序的任务列表。求值是**纯函数**，不碰网络、不碰存储，所以可以直接测。

- **今天** = 逾期 ∪ 截止时间落在当前逻辑日内的任务。**逾期置顶并标红，下面才是今天到期的**——「今天」不是一个干净的截止时间区间。
- **最近七天** = 截止时间落在从今天起的七个逻辑日内。
- **所有** = 全部未完成任务。v1 让我看不到的就是这一个。

三个视图作为清单列表页里的行出现，用前缀与真实清单区分；进去看到过滤后的任务；在视图里每条任务要显示**属于哪个清单**——视图不是容器，同一个清单名在这里重复显示是必要信息。

与日期有关的判断全部走当前逻辑日，不走自然日。

## Acceptance criteria

- [ ] 清单列表页里出现三个内置视图，与真实清单一眼可分
- [ ] 「今天」显示逾期 ∪ 今天到期，逾期置顶且标红
- [ ] 边界配成 `04:00` 时，凌晨两点看到的仍是同一个逻辑日的截止任务，且截止于昨天 23:00 的任务归在今日而不是被判成逾期
- [ ] 「最近七天」显示截止时间落在当前逻辑日起七个逻辑日内的任务
- [ ] 「所有」显示全部未完成任务
- [ ] 视图求值是纯函数：给定视图定义、缓存与逻辑日，输出确定的、排好序的任务列表
- [ ] 视图里的每条任务显示所属清单名
- [ ] 内置视图与自定义视图共用同一条求值路径
