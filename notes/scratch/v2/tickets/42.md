## What to build

清单列表页上按 `n` 建清单（输入名称，可以挑一个颜色）、按 `e` 改名称与颜色、按 `d` 一次 y/n 确认后删除。三种都立即推送。

**删除清单的确认文案要如实**：删掉一个清单时它里面的任务在服务端会发生什么，官方文档没写、我们也没有实测——文案必须说「不知道」，并且**不承诺任何恢复手段**。

清单的建 / 改表单与视图的条件表单是**同一个浮层**，按选中行的类型决定字段（视图那张工单会用到同一个浮层，谁先落地谁把浮层壳子搭出来）。

项目组只能显示不能改：清单的创建与更新接口都不接受项目组字段，所以客户端做不到把清单放进项目组，也改不了它的归属。

这张工单阻塞于剪枝那张——没有剪枝，删掉的清单刷新一次就又回来了。

## Acceptance criteria

- [ ] 清单列表页按 `n` 建清单，能输入名称并挑颜色
- [ ] 按 `e` 改当前清单的名称与颜色
- [ ] 按 `d` 一次 y/n 确认后删除当前清单
- [ ] 删除确认文案如实说明「里面的任务会怎样，文档没写」，且不承诺恢复
- [ ] 取消确认时不发生任何写入
- [ ] 三种操作都立即推送，失败进重试队列
- [ ] 新清单建完出现在清单列表页；删掉的清单不再出现在清单列表页（刷新之后也不回来）
- [ ] 与视图共用同一个浮层，按选中行类型决定字段
- [ ] 不写项目组字段（接口不接受），也不假装能改
