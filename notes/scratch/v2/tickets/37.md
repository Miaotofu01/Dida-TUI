# Ticket #37 — 任务行的样子与顺序

Labels: ['ready-for-agent']
State: open

## Parent

#30

## What to build

任务列表页里每一行的内容与整份列表的顺序。用户一眼要能看出：这条什么时候到期、重不重要、有没有标签、是不是重复任务、有没有提醒、是不是逾期、是不是已经完成。

- 行内容：优先级标记、标题、**人类可读的截止时间**（「今天 18:00」「昨天 09:00」「3 天前」，没有日期读作「—」）、标签、**重复标记**、提醒标记。
- 全天任务显示成「今天」而不是「今天 00:00」——全天任务的截止时间是一个**日期标记**（当天 00:00），不是时刻；按时刻算会在边界配成 `04:00` 时把「今天」的全天任务算成昨天。
- 一眼分得清「没有截止时间」和「今天截止」。
- 逾期标红。
- 排序：**截止时间升序 → 优先级从高到低 → 没有截止时间的排在有截止时间的后面 → 已完成的一律沉到最底**。客户端统一重排，不看服务端的 `sortOrder`。
- 已完成的任务在清单里**划掉显示、沉到最底**，并且**只显示最近 7 天**完成的（配置项的默认值从 24 小时改成 168）。
- 任务行里的清单名：在清单视图里**不重复显示**（同一个清单名重复一百遍是噪音），在视图里**必须显示**。
- 光标跨刷新存活。

**已完成流有两处必须写清**：拉取要**同时**按完成时间窗口与完成状态过滤——取消完成之后完成时间戳**不会被清空**，只按时间筛会把已取消完成的任务又捞回来；本地判定「已完成」一律看状态（2 是完成，0 是正常，-1 是已放弃），不看有没有完成时间。

## Acceptance criteria

- [ ] 行显示优先级标记、标题、人类可读的截止时间、标签、重复标记、提醒标记
- [ ] 全天任务读作「今天」而不是「今天 00:00」，且在边界配成 `04:00` 时不被算成昨天
- [ ] 「没有截止时间」与「今天截止」一眼可分
- [ ] 逾期任务标红
- [ ] 排序为：截止时间升序 → 优先级降序 → 无日期的排在后面 → 已完成的沉底
- [ ] 已完成的任务划掉显示并沉底
- [ ] 只显示最近 7 天完成的，更早的不占屏幕
- [ ] 完成时间窗口配置项的默认值已改成 7 天
- [ ] 拉取已完成流时同时按完成时间与状态过滤；已取消完成的任务不会被捞回来
- [ ] 本地判定已完成只看状态，不看完成时间戳
- [ ] 清单视图里不重复显示清单名，视图里显示
- [ ] 后台刷新后光标仍在原来那一条上
