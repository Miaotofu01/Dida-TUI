## What to build

v2 的界面一直是功能先落地、样子随缘：真正属于仓库的 CSS 只有三条规则，其余全是 Textual `textual-dark` 的默认值。真实使用后判定**不够酷炫、偏冷**。这张工单是视觉地基——把风格变成一个**系统**，让后面 13 张在飞工单继承它，而不是各自发明临时样式。

边界：**只动外观、节奏、动效。不碰信息架构、不碰键位流程**，所以 #35–#48 的验收标准全部有效。行高、分区标题、分隔与留白在范围内；**密度本身不变**。

四件事：

**1. 颜色跟随终端主题。** 现在 `App.ansi_color` 默认 `None`，Textual 把每个 `ansi_*` 改写成真彩色（内建 Monokai 配色表），所以 `ansi_cyan` 出去是 `\x1b[38;2;88;209;235`，用户的终端主题**完全没被用到**。`docs/architecture.md:36` 那条「只用 16 色」的规则在源码里成立、在像素上不成立——附带后果是 `PENDING_STYLE = "bold yellow"` 实际渲染成橙色 `#FD971F`。设 `App(ansi_color=True)` 之后同一条 CSS 出去是 `\x1b[36m`，**由终端主题决定**。（本会话已实测两端。）

**2. 视觉常量只有一个出处：`tui/theme.py`。** 调色板、间距、边框、字重、动效时长全在那里，页面只引用语义名（`accent` / `overdue` / `muted` / `row-height` …），不写具体颜色。实测一次改版要碰五处（app 的 CSS、浮层 CSS、各页面约 20 处 `Text(style=…)`、主题默认值、`keys.py` 的排版算术），没有单一改动点的话「跟随主题」会在五处各自漂移。

**3. chrome 与身份：顶栏 + 状态栏，去掉 Footer。** 顶栏说「你在哪」（词标 + 导航路径面包屑），状态栏说「数据怎么样」（已同步 · 待推送 · 逻辑日）。底部原本其实是**两行**（状态栏在 Textual 的 Footer 之上），所以顶栏是拿 Footer 换来的，**chrome 净增 0 行**。另加：固定强调色贯穿、统一符号语言（前缀字符/优先级/完成/提示符一套）。

**4. 先修两个宽度 bug，再改风格。** 风格里的「节奏」靠对齐，而这两个 bug 恰好会把对齐弄坏：
- `☰`（真实清单的前缀）被 rich 算成 **2 格**，而它是东亚**中性**宽度 → 每行比终端实际画的宽 1 格。今天没有对齐列所以看不见，一旦引入对齐就错位。
- 60 列时长中文标题会**折行**，把光标字形挤到单独一行并弄坏 `scroll_cursor_into_view()`；现在没有任何东西设截断。

顺带：结构字形不许用东亚**歧义**宽度（`▣ ★ · ─ │ ╭╮╰╯ ↑↓` 在 CJK 字体下会变双宽，用户 `LANG=zh_CN.UTF-8`）；Nerd Font 图标（用户已装 FiraCode NF）**只许**出现在错了也不破对齐的装饰位。

## Acceptance criteria

- [ ] `App(ansi_color=True)`；一条**渲染级**断言：强调色发出的 SGR 是 `\x1b[36m` 而不是 `\x1b[38;2;…`
- [ ] 强调色 = 槽 6（软薄荷）；页面背景 = `ansi_default`（发出 `\x1b[49m`，即用户自己的背景，不覆盖）；浮层面 = `ansi_black`
- [ ] 所有视觉常量只在 `tui/theme.py` 一处；页面与浮层里没有具体颜色值
- [ ] 守卫**做成真的**，两条：源码扫描扩到 hex / `rgb()` / `hsl()` / 命名色 / `$` 主题变量；渲染级 SGR 断言
- [ ] 顶栏显示词标 + 当前导航路径；状态栏保留现状三项；**Footer 已去掉**；chrome 总行数不超过现在
- [ ] `☰` 换成宽度无歧义的字形；有测试盯住结构字形的宽度（现在一条都没有）
- [ ] 行文本**截断不折行**：60 列下一个长中文标题不把光标字形挤到单独一行、不弄坏 `scroll_cursor_into_view()`
- [ ] 动效：换层 = 横向平移；光标 = **选中立即到位**、装饰性光标条随后追上（≤120ms）；同步 = 超阈值（~300ms）才转圈；完成/失败 = **原生 toast**（`App.notify()`）
- [ ] `animations = auto|on|off` 开关，默认 `auto`（ssh/低能力终端关掉）
- [ ] **层级不靠颜色亮度**：用户槽位 8–15 与 1–6 同值，加亮不带来对比——层级只用字重 / `dim` / 反色 / 下划线 / 留白
- [ ] ADR-0007 落地；`docs/architecture.md:36` 改成事实（现在那条描述的是假象）
- [ ] 只提供 `overdue` 语义 token，**不实现**逾期标红——它归 #37（`TaskItem` 没有 overdue 位，TUI 不许判断日期）
- [ ] `uv run pytest` 全绿（基线 407 passed + 新增）；`uv run dida` 在真 pty 下起得来
- [ ] 真 pty 验收：三页 + 浮层 + toast + 平移 + 光标追赶都实际渲染过（headless `run_test()` 看不到 toast）
