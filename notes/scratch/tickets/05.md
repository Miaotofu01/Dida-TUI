## What to build

新建输入框和改期输入框共用的一行语法：`明天下午3点交季度报告 !高 #工作` 一次写完日期、优先级和标签。日期写法解析不出来时（例如 `13-45`）明确告知，而不是静默建出一个没有日期的任务、或者把它当标题的一部分吞掉。

日期解析器是纯函数：输入一行文本，输出标题、可选截止时间、可选优先级、可选标签列表，以及解析诊断信息（哪些部分没被识别）。语法与边界行为以 spec 的「日期解析器语法」表为准，两张票里最容易被忽略的两条是：只给时刻且该时刻已过时落到**下一个逻辑日**，以及「周三」在当前逻辑日就是周三时表示今天、「下周三」才表示下一个自然周的周三。

## Acceptance criteria

- [ ] 「今天 / 明天 / 后天 / 周X / 下周X / +3d / 3-15 / 14:00 / 明天下午3点」都能解析
- [ ] 相对日期从当前逻辑日算起，而不是从自然日算起
- [ ] 只写时刻（如 `15:00`）且该时刻已过时，落到下一个逻辑日
- [ ] 「周三」在当前逻辑日就是周三时表示今天；「下周三」表示下一个自然周的周三
- [ ] `!高` / `!中` / `!低` / `!1`…`!3` 解析成优先级；`#标签` 解析成标签
- [ ] 返回诊断信息；疑似日期但解析失败时（如 `13-45`）明确提示，不静默吞进标题
- [ ] 纯函数，直接测试，不依赖任何假件；不依赖系统时钟
