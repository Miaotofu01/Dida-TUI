## What to build

在空仓库里立起最小可安装、可运行、可测试的骨架，并建立后续所有工单都要用的两个测试接缝。

敲 `dida` 能起一个占位界面，按 `q` 能干净退出；项目用 Python 3.12 + Textual，以 `uv tool install -e .` 装成全局 `dida` 命令。这一张不实现任何业务行为——它的价值是把「可注入的 HTTP 传输层」和「可注入的时钟」这两个接缝先钉下来，后面每张工单的测试才有地方落。接缝二（传输层可注入）与「必须可注入的时钟」都出自 spec 的 Testing Decisions。

## Acceptance criteria

- [ ] `uv tool install -e .` 之后，全局 `dida` 命令能启动
- [ ] 按 `q` 干净退出；单进程，无守护进程、无开机自启
- [ ] 已建立可注入的 HTTP 传输层：测试能注入假传输并断言请求（方法、URL、认证头、请求体字段）
- [ ] 已建立可注入的时钟：测试能控制「现在」
- [ ] 占位界面能渲染、能退出，不调用任何业务逻辑
- [ ] 测试套件能跑起来并通过

## Blocked by
