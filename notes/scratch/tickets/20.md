## What to build

实测 `PATCH /open/v1/task/{id}` 的 PATCH 语义：**省略的字段是否真的被保留**。这条事实直接决定改期（#13）的正确实现——如果省略字段会被清空，那么「只改截止时间」的写回就会静默抹掉描述、标签或子任务，而这正是 spec 想避免的那类静默失败。

方法是实测，不是读文档：取一个字段齐全的临时任务，只改截止时间、省略其余字段，回读并逐字段比对。把结论写进 ADR-0002 或 spec issue #1 的评论里；若结论是「省略即清空」，同时记录改期必须显式回写全部字段。

## Acceptance criteria

- [ ] 用一个字段齐全的临时任务实测：只改一个字段、省略其余，回读比对
- [ ] 结论明确回答「省略的字段是否被保留」
- [ ] 若省略即清空，记录改期的正确写回方式（显式回写全部字段）
- [ ] 结论落到 ADR 或 spec issue 的评论里，后续工单可引用
- [ ] 不修改 #13 之外的既有决策
