## What to build

一个窄接口的滴答 API 客户端，把服务端的**静默失败**挡在本地。它对外提供列清单、按清单取未完成任务、取单个任务、新建、更新、完成、删除、按完成时间窗口取已完成任务、列标签；内部承担 Bearer 认证、领域对象与 API 字段的映射、时区原样保留与回写、未知字段透传。

四个本地守卫是这一张的重点，因为它们对应的服务端行为都不报错，只在几天后表现为「任务怎么不对」：

- 日期格式在发出前严格校验（非法日期会被服务端静默忽略）
- 没有截止时间或开始时间的任务**绝不**写重复规则（会被服务端静默清空）
- 回写时把服务端返回的未知字段一并带回（否则手机端设置的东西会被抹掉）
- 时区字段原样保留并回写（写错会静默位移截止时间）

一切失败表达成结构化错误（网络失败、认证失败、服务端拒绝、字段被静默忽略），不把裸异常抛给 UI。传输层可注入，只钉请求形状与守卫，不在这里测业务逻辑。

## Acceptance criteria

- [ ] 测试用假传输层能断言每个端点的请求形状：方法、URL、认证头、请求体字段
- [ ] 非法日期在发出请求之前被本地拦截并表达成结构化错误
- [ ] 没有截止时间或开始时间的任务绝不产出重复规则字段
- [ ] 回写时服务端返回的未知字段被一并带回
- [ ] 时区字段原样回写，截止时间不发生静默位移
- [ ] 所有失败都是结构化错误，没有裸异常抛给 UI
- [ ] 不在此处测业务逻辑（分组、排序、逾期判定不属于这一张）
