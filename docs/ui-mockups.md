# dida-tui 界面候选方案（v1 的设计记录，已被 v2 取代）

> **状态：历史记录。** 下面是 v1「今日执行台」的四个候选布局，**不是现状**。
>
> - 当时选定的是 **C（三栏：清单 + 今日 + 详情）**，并按窄屏三档降级实现（工单 #18）。
> - v2 推翻了那个定位：改成**一栏、三层页面**（清单列表页 → 任务列表页 → 任务详细页，`enter` 向下、
>   `esc` 向上），「今天」降级成三个内置视图之一。理由与作废清单见
>   [ADR-0004](adr/0004-terminal-client-not-today-console.md)。
> - 于是 C 连同 `Tab` 焦点切换、清单浮层、窄屏响应式降级一起在 #34 删掉了：一栏不需要降级。
> - 四份稿子留在这里当设计记录，仓库里没有任何地方链接它们。
>
> 仍然生效的只有下面「配色与标记」里的两条通用规矩：**颜色只用终端 16 色、不写死 hex**，以及
> **待推送 > 0 时状态栏那一格高亮**。其余（三栏线框、分组标题、已完成折叠区）随 v1 布局一起作废。
>
> ⚠ 稿子里的清单名与任务名（`工作` / `生活` / `学习` / `交季度报告` / `研究 v2ray 分流规则` …）是**示例数据**，
> 只是例子，不代表你的账户里有什么。

四个候选布局用同一份示例数据绘制：`❯` = 光标行（实际渲染为反色）；`▸` = 可展开的折叠区。

## 配色与标记（四方案共用）

| 元素 | 表现 |
|---|---|
| 逾期分组标题 | 红 |
| 优先级高 `!` / 中 `~` / 低 `·` | 红 / 黄 / 暗灰；无优先级显示 `·` |
| 光标行 | 反色 |
| 待推送 > 0 | 状态栏黄色 `待推送 2`；归零后恢复普通色 |
| 已完成 | 暗灰 + 删除线 |
| 颜色 | 只用终端 16 色，不写死 hex |

## 取舍

| 方案 | 得 | 失 | 最小宽度 |
|---|---|---|---|
| A | 横向全部给标题，中文长标题不折行 | 看不到全局负载；换清单要按 Tab | 60 列 |
| B | 清单与数量常驻，上下文不丢 | 标题列少约 18 列 | 80 列 |
| C | 不切视图即可看描述/子任务 | 标题只剩约 30 列，窄屏必须降级 | 110 列 |
| D | 数字键直达 | 清单多于 6 个要翻页 | 60 列 |
