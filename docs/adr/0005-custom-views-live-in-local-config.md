# 自定义视图只存在本地配置文件里

用户要能建立自己的过滤视图（「高优先级未完成」这类）。滴答清单 API 有 `task/filter`，但那是一次性查询——**没有任何端点能保存一组过滤条件**。所以自定义视图的定义只能落在本地配置文件里，内置视图（今天、最近七天、所有）则由代码写死。

## Consequences

- 同一个视图在手机和网页版上**不存在**，换一台机器就没了，也没法在官方客户端里编辑它。这是 API 的能力上限，不是实现疏漏——**不要试图「把视图同步上去」**，那条路不存在。
- 视图的过滤在**本地对全量缓存求值**，不经过 `task/filter`。这顺带绕开了它的两个坑：它的日期区间过滤的是 `startDate` 而不是 `dueDate`（所以「本周到期」这类条件根本没法用它表达），以及它硬顶 200 条、没有分页。
- 视图不是容器：视图里的任务仍然住在各自的清单里，在视图里新建任务需要一个明确的落点（落到收集箱）。
